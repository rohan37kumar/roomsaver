# Third-party notices

RoomSaver vendors the following libraries in `third_party/`. No package manager is
needed; each keeps its original license, reproduced in or next to its sources.

| Library | Version / source | License | License text |
|---|---|---|---|
| [GLM](https://github.com/g-truc/glm) | commit `6f14f47` (headers only) | MIT (or Happy Bunny) | `third_party/glm/copying.txt` |
| [glad 2](https://github.com/Dav1dde/glad) | generated loader, OpenGL 3.3 core | (WTFPL or CC0-1.0) and Apache-2.0 (Khronos spec) | header of `third_party/glad/src/gl.c` |
| [Khronos `khrplatform.h`](https://registry.khronos.org/EGL/api/KHR/khrplatform.h) | bundled with glad | MIT-style (Khronos) | header of `third_party/glad/include/KHR/khrplatform.h` |
| [stb](https://github.com/nothings/stb) | `stb_image`, `stb_image_write`, `stb_truetype` | Public domain or MIT | end of each header |
| [cgltf](https://github.com/jkuhlmann/cgltf) | single header | MIT | end of `third_party/cgltf/cgltf.h` |
| [KISS FFT](https://github.com/mborgerding/kissfft) | `kiss_fft`, `kiss_fftr` | BSD-3-Clause | `third_party/kissfft/COPYING` |

At runtime RoomSaver uses only APIs that ship with Windows: Win32, WGL/OpenGL,
C++/WinRT (`Windows.Media.Control`) and WASAPI. It never connects to the network.
